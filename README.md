# Ribera Baja Explora

Guía turística web de la Comarca Ribera Baja del Ebro (demo): mapa de los diez pueblos, 34 lugares, rutas temáticas, fichas en español, inglés, francés, alemán y portugués con audio, códigos QR, guías locales y panel de gestión de contenidos.

Demo: https://hoppafrost-glitch.github.io/ribera-baja-explora/
